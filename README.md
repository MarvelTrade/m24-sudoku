# Москва 24 | Судоку

Мобильная веб-игра **Судоку** в эфирном стиле телеканала «Москва 24». Работает прямо в браузере телефона, не требует сборки и может быть установлена на экран «Домой» как PWA (включая офлайн-режим).

## Возможности
- **4 уровня сложности**: Лёгкий (42), Средний (34), Сложный (28), Эксперт (23) — генерация головоломок с единственным решением.
- **Удобное управление на телефоне**: адаптивная сетка `100dvh` без лишнего скролла, крупная цифровая панель с подсчётом оставшихся цифр.
- **Заметки (карандаш)**: отметка кандидатов в клетках с автоматическим удалением при вводе правильной цифры.
- **Отмена хода, подсказки, пауза и автосохранение** прогресса и статистики в `localStorage`.
- **Светлая и тёмная студийные темы** + звуковые эффекты (можно отключить).
- **Офлайн-режим (PWA)**: работает даже в метро после первого открытия.

## Как выгрузить на GitHub и играть с телефона (GitHub Pages)

1. Создайте новый публичный репозиторий на [GitHub](https://github.com/new), например `m24-sudoku`.
2. Выполните в папке проекта команды:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Moscow 24 Sudoku"
   git branch -M main
   git remote add origin https://github.com/<ВАШ_ЛОГИН>/m24-sudoku.git
   git push -u origin main
   ```
3. Откройте репозиторий на GitHub → **Settings** → **Pages**.
4. В разделе **Build and deployment** выберите:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` / `/ (root)`
   Нажмите **Save**.
5. Через 1–2 минуты игра станет доступна по адресу:
   `https://<ВАШ_ЛОГИН>.github.io/m24-sudoku/`
6. Откройте эту ссылку на телефоне (в Safari на iOS или Chrome на Android) и выберите **«На экран „Домой“»** / **«Установить приложение»**, чтобы запускать судоку как полноценное приложение.
